# Vision

ktask is a beautiful terminal application that turns software-development goals into an ordered queue of tasks and runs them through to checked results.
The owner supplies high-level goals, constraints, and observable success criteria. A capable execution model owns investigation, design, implementation, and verification within each task. Stronger models independently review the result and diagnose or repair failures. Separate planning and task breakdown are optional; human intervention is reserved for consequential product decisions.
The user manages the queue and controls execution through a visual workspace with full mouse and keyboard support, seeing what is happening, what went wrong, and what needs their attention.
A CLI lets agents manage the same tasks and execution as the user.
